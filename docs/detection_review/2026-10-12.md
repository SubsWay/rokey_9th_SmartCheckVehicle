## 최종 모델과 한계

기존 모델의 잘못된 train 캐시는 점등 21장·소등 0장으로 남아 있었다.
실제 라벨은 점등 11장·소등 10장이다. 검증 캐시도 점등 3장·소등 0장으로
남아 있어 새로 만들었다. 캐시를 바로잡고 재학습했으며, 기존 압력계 특징을
보존하는 추가학습본(초기 10층 고정, AdamW lr 0.0005)을 최종 진단 모델로 선택했다.
좌우·상하 반전은 바늘 상태 라벨의 의미를 바꿀 수 있어 비활성화했다.

최종 검증 precision은 **0.9353**, recall **1.0000**, mAP50 **0.9950**,
mAP50–95 **0.9568**. 44 epoch에서 조기 종료, best epoch 24.
검증 설정은 conf=0.25, iou=0.45, imgsz=640이다.
압력계 3클래스 precision은 각각 1.0, 비상구 점등은 0.7332, 소등은 0.9435다.
점등·소등에 배경 오검출이 각 1건 남아 있다. 전체 95% 기준은 미통과다.

비상구의 같은 원본에서 만든 증강본을 나눈 평가이므로 새로운 환경의 성능을
보장할 수 없다. 현재 모델은 진단용이고 TEST_PLAN 전체 통과로 표시하지 않았다.
현재 카메라 프레임 미수신 때문에 최종 모델의 실영상 확인도 남아 있다.

## 시험 재현

소스 패키지 README의 환경·rosdep 등록·빌드 순서를 먼저 따른다.

```bash
source /opt/ros/jazzy/setup.bash
cd ros2_ws
source install/setup.bash
python3 -m pytest src/scv_detection/test/test_detection_alert.py -q
python3 ../scripts/smoke_detection_headless.py \
  --weights "$(ros2 pkg prefix --share scv_detection)/models/best.pt" \
  --log /tmp/scv-headless-smoke.log
```

시험용 JPEG 송수신은 로봇 통신과 섞이지 않게 별도의 ROS_DOMAIN_ID와 localhost
환경에서 수행한다. 실영상 비교는 정상 로봇 통신 환경에서
`scripts/compare_detection_live.py --old <이전 모델> --new <최종 모델> --topic <압축 영상 주소> --output-dir <결과 폴더>`로 실행한다.
